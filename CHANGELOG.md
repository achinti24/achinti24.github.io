# Changelog

Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y versionado [SemVer](https://semver.org/lang/es/).

## [1.0.1] - 2026-09-27

### Cambiado

- GitHub Pages sirve el sitio como archivos estáticos sin procesarlo con Jekyll (`.nojekyll`).

## [1.0.0] - 2026-09-27

### Añadido

- Estructura HTML semántica one page con meta tags de SEO, Open Graph y favicon.
- Design tokens (color, tipografía, espaciado, movimiento) y fuentes auto-alojadas.
- Header fijo con menú hamburguesa accesible y resaltado de la sección activa.
- Secciones: Hero, Sobre mí, Habilidades, Proyectos, Formación y experiencia, Contacto y Footer.
- Proyectos como casos de estudio: Casacas Colegial, Chatbot para WhatsApp, Menú 3D, IA-Ludik y Eye System.
- Descarga de hojas de vida (Full Stack, Frontend, Backend, Automatización e IA) y botón para copiar el email.
- Microinteracciones (aparición al hacer scroll, brillo que sigue al cursor, animación de entrada) que respetan `prefers-reduced-motion`.
- README con capturas, stack, decisiones de diseño y flujo de Git.
